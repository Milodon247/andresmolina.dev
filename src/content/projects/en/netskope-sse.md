technologies: [Netskope, CASB, Next Gen SWG, DLP, SSE]
---

Implementation of Netskope to secure web and cloud application access for more than 500 users
working from different countries and in many different roles:

- **CASB**: visibility and control over the cloud applications in use, sanctioned and unsanctioned.
- **Next Gen SWG**: web traffic inspected and filtered wherever users connect from.
- **DLP**: data loss prevention policies to stop sensitive information from leaving through web and
  cloud channels.
- **Role-based policies**: controls adapted to each role and country instead of one rule set for
  everyone.
