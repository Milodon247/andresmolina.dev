I lead the DevSecOps strategy at Betway across three areas of responsibility: **SDLC security**,
**cloud security** on Azure and AWS, and **Kubernetes security**.

- **SDLC security**
  - Design DevSecOps pipelines in Azure DevOps, GitHub Actions and GitHub that embed SAST, DAST and software composition analysis (SCA) in build and release stages, catching vulnerabilities before merge rather than in production.
  - Automate vulnerability scanning, compliance evidence collection and remediation workflows across the CI/CD toolchain, reducing manual audit preparation and shortening time to remediate critical findings.
- **Cloud security**
  - Design and maintain reusable Terraform modules for Azure and AWS landing zones, standardizing network segmentation, identity, logging and tagging baselines across subscriptions and accounts.
  - Define and enforce policy-as-code guardrails covering encryption, network exposure and configuration drift, blocking non-compliant infrastructure changes before they reach production.
- **Kubernetes security**
  - Harden containerized workloads on Docker and Kubernetes through image vulnerability scanning, admission control policies and runtime security monitoring.
- Act as an embedded security architecture partner to engineering squads, advising on secrets management, least-privilege IAM design and secure-by-default deployment patterns.
