I own the end-to-end DevSecOps strategy across Azure and AWS, embedding security as code into the
full software delivery lifecycle for engineering and platform teams.

- Architect end-to-end DevSecOps pipelines across Azure DevOps, GitHub Actions and GitHub, embedding
  SAST, DAST and software composition analysis (SCA) into build and release stages to catch
  vulnerabilities before merge rather than in production.
- Design and maintain reusable Terraform modules for Azure and AWS landing zones, standardizing
  network segmentation, identity, logging and tagging baselines across subscriptions and accounts.
- Define and enforce policy-as-code guardrails covering encryption, network exposure and
  configuration drift, blocking non-compliant infrastructure changes before they reach production.
- Harden containerized workloads on Docker and Kubernetes through image vulnerability scanning,
  admission control policies and runtime security monitoring.
- Automate vulnerability scanning, compliance evidence collection and remediation workflows across
  the CI/CD toolchain, reducing manual audit preparation and shortening time to remediate critical
  findings.
- Act as an embedded security architecture partner to engineering squads, advising on secrets
  management, least-privilege IAM design and secure-by-default deployment patterns.
